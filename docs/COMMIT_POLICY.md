# Политика коммитов

Один коммит соответствует одному логическому действию. Каждый коммит содержит:

- причину изменения;
- перечень изменений;
- выполненные проверки;
- ограничения, если они остались.

Работа выполняется в `feature/rag-pgvector`. В `main` изменения попадают только после финальных проверок.
