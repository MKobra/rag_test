# Безопасность и ограничения

## Реализовано

- Простая регистрация и вход по email/паролю.
- Пароли хранятся как PBKDF2-HMAC-SHA256 с уникальной солью и 310000 итерациями.
- Доступ к документам и чатам ограничен `owner_id`.
- JWT подписывается HMAC-SHA256 и имеет срок действия.
- Bearer-токен не попадает в URL.
- Расширение файла проверяется до индексации.
- Размер файла ограничен 10 МБ.
- Вопросы и загрузки ограничены rate limit.
- Ответы не используют внешний контекст и содержат только проверенные источники.
- Пользовательский текст выводится через `textContent`/HTML-экранирование.

При генерации темы первые 4000 символов документа отправляются в Groq. Для конфиденциальных документов это нужно учитывать при выборе политики хранения и провайдера модели.

## Ограничения MVP

Rate limit хранится в памяти одного процесса. При нескольких workers или нескольких экземплярах приложения нужен Redis.

Для production также нужны HTTPS, reverse proxy с лимитом body size, CORS allowlist, централизованный аудит и ротация JWT secret.
